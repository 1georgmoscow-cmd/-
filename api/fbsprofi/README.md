# FBSPROFI API

Ручки-обёртки над сайтом FBSPROFI: сайт отдаёт HTML, ручки возвращают JSON.

## Установка

1. Скопируйте `.env.example` в `.env` и при необходимости поправьте значения.
2. Папка `storage/sessions/` должна быть доступна для записи PHP (в неё
   складываются cookies и метаданные сессий), но закрыта от прямого доступа
   из веба.
3. Требуется PHP 8.1+ с расширениями `curl` и `dom`.

## POST /api/fbsprofi/auth/login.php

Вход логином и паролем для тех, у кого нет бейджа (владелец фулфилмента,
бухгалтерия, клиент). Определяет кабинет и выдаёт токен.

Запрос (`form-data`, `x-www-form-urlencoded` или JSON):

    login=LOGIN&password=PASSWORD

Ответы:

| Код | Тело |
|-----|------|
| 200 | `{"ok":true,"token":"...","cabinet":"owner|accounting|client","expires_at":<ts>}` |
| 400 | не передан логин или пароль |
| 401 | неверный логин или пароль |
| 405 | не POST |
| 502 | сайт недоступен или кабинет не распознан |

Токен из ответа передавайте в остальные ручки для работы внутри кабинета.
